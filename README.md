# Todo Life Dashboard

A simple, fast, client-side productivity dashboard built with:

- HTML
- CSS
- Vanilla JavaScript
- Browser Local Storage API

## Features

- Time-aware greeting
- Current time and date
- 25-minute focus timer with Start, Stop, and Reset
- Add, edit, complete, and delete tasks
- Tasks persist in Local Storage
- Quick Links with add/remove functionality
- Quick Links persist in Local Storage
- Responsive layout for desktop and mobile
- No backend and no build step

## Project structure

```text
todo-life-dashboard/
├── index.html
├── css/
│   └── style.css
├── js/
│   └── app.js
└── README.md
```

## Run

Open `index.html` directly in Chrome, Firefox, Edge, or Safari.

No installation, backend, framework, or test setup is required.
